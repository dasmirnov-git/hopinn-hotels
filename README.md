# Hopinn — презентация проекта для отелей

Презентация проекта Hopinn для отелей, включая веб-калькулятор условий и скачиваемую PDF-версию.

Основной адрес: https://4hotels.hopinn.ru/

Прежний адрес продолжает работать: https://dasmirnov-git.github.io/dimas_pub_/hopinn-hotels/

## Публикация

GitHub Pages публикует ветку `main`, каталог `/`. Файл `CNAME` закрепляет домен `4hotels.hopinn.ru`.

DNS у регистратора: `CNAME`, имя `4hotels`, значение `dasmirnov-git.github.io.`, TTL 3600 или по умолчанию.

После распространения DNS GitHub автоматически выпускает сертификат. Когда он готов, включить Enforce HTTPS в Settings → Pages.

HTML сохраняет `noindex, nofollow, noimageindex, noarchive`. Это инструкция поисковикам, а не ограничение публичного доступа.
